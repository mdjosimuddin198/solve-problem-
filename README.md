# Problem Solving with JavaScript

This repository contains solutions to various **problem-solving challenges** collected from the **Programming Hero** platform and similar practice sources.
The main goal of this repository is to **practice, improve, and showcase strong problem-solving skills** using **modern JavaScript (ES6+)**.

---

## Key Features

- Solutions written in clean and modern JavaScript
- Problems organized by topic and difficulty
- Focus on logic building and interview preparation
- Regularly updated with new problems and solutions

- Sorting and Searching
- Recursion and Closures
- Async and Promise-based problems
- Real-world logic problems
